# Gym App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable, offline-first gym logging app for Vik (Samsung S25 Ultra, Chrome) that opens on today's session, logs sets in one tap, syncs to his Google Sheet, and controls Spotify.

**Architecture:** Svelte SPA built by Vite, served from GitHub Pages under `/gym-tracker/`, installed as a PWA. All state lives in IndexedDB first; pure TypeScript modules hold every rule (targets, PRs, session choice, stats, timers) and are unit-tested; a queue pushes set changes to an Apps Script web app bound to the Sheet. Spotify is driven through the Web API with PKCE.

**Tech Stack:** Vite 6, Svelte 5, TypeScript 5, Vitest, @testing-library/svelte, fake-indexeddb, idb, motion, vite-plugin-pwa, @fontsource-variable/albert-sans, @fontsource/red-hat-display, Playwright (one e2e smoke), Google Apps Script, Spotify Web API.

**Spec:** `docs/superpowers/specs/2026-11-11-gym-app-design.md` (visual reference `docs/preview.html` — copy its tokens, layout and motion; it is the approved look).

## Global Constraints

- Base path `/gym-tracker/`; hash routes only: `#/`, `#/workout`, `#/summary`, `#/progress`, `#/week`, `#/settings`.
- Units kg; dates are local `YYYY-MM-DD` (Asia/Kolkata on device); a workout's date is the date it was **started**.
- Colours: ground `#0B0D11`, surface `#13161C`, raised `#1A1E26`, line `#242934`, text `#E8EAEE`, muted `#8C94A3`, blue `#4C8DFF`, blue-deep `#16305C`, blue-ink `#DCE7FF`, amber `#F2B544`, Spotify green `#1ED760`. Text contrast ≥ 4.5:1.
- Fonts bundled (no network): Albert Sans for text/headings, Red Hat Display for numbers, `font-variant-numeric: tabular-nums`.
- Easing: `--ease-out: cubic-bezier(0.23,1,0.32,1)`, `--ease-drawer: cubic-bezier(0.32,0.72,0,1)`; UI motion < 300 ms (drawers 420 ms); press `scale(0.97)` 160 ms; `prefers-reduced-motion` → opacity fades only.
- Touch targets ≥ 48 px; ± buttons 64 px; hold-to-repeat 450 ms delay then every 90 ms; swipe step every 22 px after a 10 px threshold.
- Rest defaults: compound 180 s, isolation 120 s, max 300 s per exercise.
- Progression: last time's set n reached repMax → `kg + step` at repMin; otherwise same kg, reps + 1 (capped at repMax). Two consecutive "felt it" sessions on an exercise → hold last kg and reps.
- e1RM = `kg * (1 + reps / 30)` rounded to 0.1.
- Warm-up and deleted sets never count toward PRs, volume, weekly sets or trends.
- Strength trend needs ≥ 3 sessions of the muscle; otherwise show "Not enough data yet".
- Workout auto-ends 15 min after its last done set.
- No secrets in the repo: script URL, script key and Spotify client ID are entered in Settings and stored in IndexedDB.
- Spotify scopes: `user-read-playback-state user-modify-playback-state user-read-currently-playing playlist-read-private user-library-read user-read-recently-played`; search `type=playlist&limit=10`.
- Copy is plain and from Vik's side ("Start workout", "Swap day", "Finish workout", "Save set"); no emoji in UI.

## Review Focus

1. **App killed mid-workout (Android frees memory while Spotify plays):** reopening must restore the in-progress workout, its done sets and the running rest timer from IndexedDB. Owning test: Task 6 `restores in-progress workout`.
2. **Sync retried after a timeout:** the same set sent twice must produce one sheet row; an edit after sync updates that row; a delete clears it. Owning tests: Task 7 `upsert is idempotent`, `delete clears row`.
3. **Workout that crosses midnight / is finished next morning:** all sets keep the start date; auto-end uses last set time + 15 min. Owning test: Task 6 `sets keep workout start date`.
4. **Exercise logged that the sheet doesn't know (custom or swapped):** script appends it to the first empty Exercises row in its slot, or "Other". Owning test: Task 7 `unknown exercise is added to library`.
5. **Spotify token expired or no active device:** controls show "Reconnect" / "Open Spotify" instead of failing silently; a 401 triggers one refresh then retry. Owning tests: Task 13 `refreshes once on 401`, `no device → needsDevice`.
